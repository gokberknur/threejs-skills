# threejs-skills

Four [Claude Code](https://claude.com/claude-code) skills that know **three.js r187 (`three@0.187.x`)** from the official
documentation, bundled offline so Claude verifies API names instead of
guessing from stale training data.

| Skill | Use it for |
|---|---|
| `threejs` | Everything three.js: scene setup, renderer choice, geometry, materials, lights/shadows, loaders (glTF/Draco/KTX2), animation, controls/picking, XR, version facts. Ships all 834 API pages plus `scripts/api.py` for offline lookup. |
| `threejs-tsl-webgpu` | TSL (Three.js Shading Language), node materials, `WebGPURenderer`, compute shaders, node post-processing (`RenderPipeline`). Ships the full TSL guide and function reference. |
| `threejs-performance` | FPS/memory problems: draw calls (`InstancedMesh`/`BatchedMesh`/LOD), textures, render-on-demand, OffscreenCanvas, shader and WebGPU cost, profiling. |
| `threejs-visual-quality` | Making scenes look right: color/tone-mapping pipeline, PBR + environment lighting, shadow quality, anti-aliasing, post-processing stacks for both renderers, atmosphere. |

Install all four together; they reference each other by sibling path.

```sh
git clone https://github.com/gokberknur/threejs-skills
cp -R threejs-skills/threejs* ~/.claude/skills/        # global, or <project>/.claude/skills/
```

## How it was built

- Sources: `threejs.org/docs` (834 API pages), `threejs.org/manual` (60 pages),
  `threejs.org/tsl` (82 guide sections + 658-entry function reference), the
  examples catalog, the GitHub migration guide and `docs/llms.txt`.
- Mechanical layers (API pages, indexes, TSL guide/reference) are generated by
  `tools/update-corpus.py`. Written layers (`SKILL.md` and the
  topic references) were digested from that corpus with every API name grepped
  against the docs and source.
- Benchmarked with the skill-creator eval loop (one prompt per skill, with vs
  without skill): the skill versions passed every assertion; the baselines
  used deprecated names (`Clock`, `RGBELoader`, `PCFSoftShadowMap`) or missed
  environment lighting and `BatchedMesh`.

## Keeping it current

three.js releases monthly. `UPDATING.md` describes the update
procedure: regenerate the corpus with one command, read the change report and
the new migration-guide section, fix the written references, bump version
strings, re-run evals.
